# MinwonRegister (무인교통단속장비 민원접수대장 및 운영현황 관리 시스템)

`MinwonRegister`는 기존 Excel VBA(`_ref_VBA`) 기반 민원접수대장 및 무인교통단속장비 운영현황 통계 매크로를 현대적인 **Electron + React 19 + TypeScript + Tailwind CSS v4 + SQLite (`better-sqlite3`) + 내장 다중 사용자 REST API 서버** 아키텍처로 전면 고도화한 데스크톱/웹 하이브리드 애플리케이션입니다.

## 주요 기능

1. **민원접수대장 통합 관리 (기존 VBA 13개 표준 항목 완벽 호환)**
   - `연번`, `접수일자`, `접수구분`, `접수번호`, `이름`, `연락처`, `위치`, `구역구분`, `민원내용`, `공단 검토일자`, `공단 검토결과`, `개선결과`, `비고` 등록·수정·삭제
   - 접수일자 / 공단 검토일자별 빠른 기간 필터(`전체`, `당월`, `3개월`, `6개월`, `9개월`, `금년`) 및 검색구분·공단 검토결과 복합 조회
   - 새로운 `접수구분` 입력 시 다음 등록부터 선택 목록에 자동 추가 (`VBA AddListboxItem` 계승)
   - 무인교통단속장비 마스터(487대) 검색 및 원클릭 위치·보호구역·장비번호 자동 입력 연동

2. **무인교통단속장비 마스터(`device.csv` 487대) 및 운영현황 자동 통계(`operator-status.xlsx`)**
   - 제주권역 무인교통단속장비 487대 기본 내장 및 신규 장비 등록·수정·삭제
   - 설치년도별 보호구역(`일반구역`, `어린이보호구역`, `노인보호구역`, `장애인보호구역`) 및 단속종류(`신호과속(고)`, `과속(고)`, `구간(고)`, `운행제한(고)`, `진입금지(고)`, `과속(이)`, `합계`) 실시간 매트릭스 집계

3. **담당자 로그인 모달 폼 및 역할 기반 권한 제어 (RBAC)**
   - 시작 시 세련된 로그인 모달 폼을 통해 사용자 인증 (`시스템 관리자`, `민원접수 담당자`, `현황 열람자`)
   - 기본 계정: 관리자(`admin` / `admin1234`), 담당자(`operator` / `oper1234`), 열람자(`viewer` / `view1234`)
   - 모든 로그인 및 민원/장비 등록·수정·삭제 작업은 감사 로그(Audit Log)에 자동 기록

4. **다중 사용자 동시 접속용 내장 REST API & 웹 서버 (On/Off 토글)**
   - 좌측 사이드바 하단 또는 `[서버]` 탭에서 **서버 기능 켜기**를 누르면 내장 REST API 및 웹 서버(`0.0.0.0:8090`)가 즉시 기동됩니다.
   - 동일 네트워크(LAN)의 다른 PC 사용자들이 웹 브라우저(`http://<서버IP>:8090`) 또는 프로그램의 `[다른 PC 서버 접속]` 모드로 접속하여 동일한 로그인 모달을 거쳐 실시간으로 민원접수대장을 함께 조회·등록·수정할 수 있습니다.
   - Server-Sent Events(`SSE`) 및 Electron IPC 브로드캐스트를 통해 한 사용자가 수정한 내역이 다른 접속자 화면에 실시간 반영됩니다.

5. **표준 관공서 양식 엑셀(`.xlsx`) 원클릭 내보내기**
   - 글꼴 `맑은 고딕 10pt`, 1행 제목 배경(`#D9E1F2`) 및 굵게, 행 높이 `25`, 모든 테두리(`#BFBFBF`), 1행 틀 고정(`A2`), 자동 필터 및 한글 폭 맞춤이 적용된 표준 `.xlsx` 파일을 `Export/` 폴더에 즉시 생성합니다.

## 실행 및 빌드 명령어

```bash
# 개발 서버 실행
npm run dev

# 타입 검사 및 단위/통합 테스트 실행
npm run typecheck
npm test

# 프로덕션 번들 빌드 및 Windows 설치/포터블 실행파일 생성
npm run build
npm run dist:win
```
