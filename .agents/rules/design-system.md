# UI/UX 디자인 시스템 규칙 (좌측 다크 아이콘 사이드바 & 화이트·슬레이트 관제 테마)

프론트엔드(`src/renderer/`)의 모든 화면과 컴포넌트는 `atoj` / `systemcheck` / `process-monitor`와 동일한 패밀리 룩 규격을 엄격히 준수한다.

## 1. 콤팩트 고정 뷰포트 및 좌측 다크 아이콘 사이드바 레이아웃
- **창 크기**: **`1180 x 740`** (`useContentSize: true`, 최소 `1040 x 680`)을 기본 창 크기로 사용하여 13개 민원접수대장 컬럼과 검색 조건이 답답함 없이 한눈에 들어오도록 구성한다.
- **전체 페이지 스크롤 금지**: 최상위 레이아웃은 `h-screen w-screen overflow-hidden flex bg-[#f1f5f9] text-[#0f172a] select-none`으로 고정하며, 테이블/목록 영역만 내부 스크롤(`flex-1 min-h-0 overflow-y-auto`)한다.
- **좌측 다크 아이콘 사이드바 (`GlobalNav.tsx`, `w-[64px] bg-[#090d16]`)**:
  - 상단: `민원` 브랜드 배지(`MinWon`) + 다중 접속 REST API 서버 상태 표시등(초록 펄스: 서버 가동 중 / 슬레이트: 단독 로컬 모드)
  - 중앙: `16px` 아이콘 + `10.5px` 2글자 한글 레이블(`대장`, `등록`, `장비`, `통계`, `서버`, `설정`, `정보`)
  - 하단: `서버켜짐/서버꺼짐` 원클릭 토글, 현재 로그인 사용자/로그아웃(`계정`) 퀵 액션 버튼 배치
- **로그인 모달 폼 (`LoginModal.tsx`)**:
  - 반투명 블러 배경(`bg-[#090d16]/60 backdrop-blur-sm`) 위에 깔끔한 화이트 카드(`rounded-[14px] border border-[#cbd5e1] bg-white`)로 배치한다.
  - 데스크톱 로컬 모드와 원격 서버 접속 모드(또는 웹 브라우저 접속) 모두에서 일관되게 동작하며, 직관적인 한글 안내와 역할 배지를 제공한다.
- **단일 테두리 시트 원칙 ("카드 안의 카드" 금지)**:
  - 테이블 영역을 감쌀 때 외곽 카드 보더 안에 또 다른 보더 박스를 중첩하지 않고, `bg-[#ffffff] border border-[#cbd5e1] rounded-[10px] overflow-hidden` 단일 시트 구조를 사용한다.
- **오프라인 내장 폰트 및 100% 한글화**: `src/renderer/assets/fonts/Pretendard-*.woff2`를 전 요소에 강제 적용하고 영문 기술 용어 대신 순수 한글 레이블만 사용한다.

## 2. 엑셀(`.xlsx`) 및 CSV 산출물 기본 서식
사용자가 별도 서식을 지정하지 않더라도 엑셀(`.xlsx`) 및 CSV 파일을 내보낼 때는 항상 아래 표준을 기본 적용한다:
- **글꼴**: 맑은 고딕, 크기 10pt (1행 제목 행은 굵게 및 연한 배경색 `#D9E1F2` 적용)
- **행 높이**: 제목 행과 데이터 행 모두 기본 높이 25 적용
- **테두리**: 데이터가 들어가는 모든 셀에 얇은 실선(모든 테두리, `#BFBFBF`) 적용
- **편의 기능**: 1행 틀 고정(`freeze_panes = "A2"`), 첫 행 자동 필터(`auto_filter`), 한글 글자 폭(1.8배)을 고려한 열 너비 자동 맞춤 적용
- **CSV 입출력**: 윈도우 엑셀에서 한글이 깨지지 않도록 `UTF-8 with BOM`(`\uFEFF`) 또는 `CP949` 자동 감지를 지원한다.
